<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| AdminUI HTTP request → SerializerDeserializeCommand | Authenticated DW admin user issues deserialize command via admin UI; query string carries `?strictMode=...` override |
| Manifest file (on disk) → SerializerOrchestrator | Manifest written by trusted Phase 42 serialize path; read on deserialize path; trust boundary because file could in principle be hand-edited between serialize and deserialize |
| OrchestratorResult.HasErrors → CommandResult.Status | Pure-function mapping that drives HTTP 200 vs 4xx response — single source of truth for client-side success detection |

## STRIDE Threat Register

This phase is a refactor on already-authenticated admin-only commands; it introduces no new external trust boundaries. The threat register focuses on regression risks introduced by the rewiring.

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-43-01 | Tampering | Manifest file on disk | accept | Phase 42 already writes `complete: true` sentinel; ManifestWriter.Read validates schemaVersion gate; admin-UI is authenticated; no new ingress in Phase 43 |
| T-43-02 | Repudiation | Per-entry log lines | mitigate | REPORT-05 / SC-5 — every dispatched entry emits a `[entryId] Status` line via existing `LogFileWriter` plumbing; observable in admin-UI log viewer without re-running |
| T-43-03 | Information Disclosure | EntryOutcome.Errors[] in HTTP response | accept | Errors[] surfaces internal exception messages just as today's `OrchestratorResult.Errors` does; admin-only endpoint; no scope change |
| T-43-04 | Denial of Service | Manifest with very large entries[] list | accept | Existing per-predicate dispatch already linear; no new amplification surface |
| T-43-05 | Elevation of Privilege | StrictModeResolver bypass via misbiwred null configValue | mitigate | SC-4 acceptance test — `StrictModeResolver.Resolve(entryPoint, configValue: null, requestValue)` is grep-asserted at every deserialize call site; entry-point default (API/CLI=true, AdminUi=false) preserved |
| T-43-06 | Tampering | OrchestratorResult.HasErrors aggregation | mitigate | SC-3 acceptance test — extends D-38-12 zero-error-equals-HTTP-200 guard test to assert any `EntryOutcome.Status == Failed` flips `HasErrors` to true; pure-function `MapStatusFromResult` is the single mapping site |
| T-43-07 | Information Disclosure | Synthetic `OrchestratorResult.RunLevelError` outcome leaking strict-mode messages | accept | Mirrors today's `OrchestratorResult.Errors` aggregation; same trust boundary |
</threat_model>

    ```csharp
    namespace DynamicWeb.Serializer.Infrastructure;

    /// <summary>
    /// Phase 43 / DESER-05 final: emits a one-time WARNING when the on-disk Serializer.config.json
    /// has `strictMode` set even though the deserialize path no longer consults it. Routes through
    /// the standard log plumbing (caller's Action&lt;string&gt; log) — no admin-UI banner, no
    /// process-wide singleton; "once per run" is implicit because each command call creates a fresh
    /// instance and the caller invokes Emit() exactly once at command start.
    /// </summary>
    public static class StrictModeDeprecationWarning
    {
        public static void EmitIfLegacyValueSet(string configPath, Action<string>? log)
        {
            if (string.IsNullOrEmpty(configPath) || !File.Exists(configPath)) return;
            try
            {
                using var stream = File.OpenRead(configPath);
                using var doc = JsonDocument.Parse(stream);
                if (doc.RootElement.ValueKind != JsonValueKind.Object) return;
                if (!doc.RootElement.TryGetProperty("strictMode", out var sm)) return;
                if (sm.ValueKind != JsonValueKind.True && sm.ValueKind != JsonValueKind.False) return;

                log?.Invoke(
                    $"WARNING: config.StrictMode is set in `{configPath}` but no longer consulted on " +
                    $"the deserialize path; use the per-call ?strictMode=true query parameter or rely " +
                    $"on the entry-point default");
            }
            catch
            {
                // Peek failure is non-fatal — the deserialize path doesn't need this; leave silent.
            }
        }
    }
    ```
